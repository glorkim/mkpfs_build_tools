# MkPFS Build Tool v1.40

**Created by: Xenogear**

![GUI](gui_screen.png)

An automated build tool using MkPFS that converts PS5 game images into compressed `.ffpfsc` format.  
Drag a folder or file (`.exfat` `.ffpkg` `.rar` `.zip` `.7z` `.zip.001` `.7z.001` `pfs_image.dat` `.ffpfsc`) to process it automatically.  
Compression reduces file size by approximately **40~60%**.  
Archived games (RAR / ZIP / 7z) can be built directly — no extraction required.  
(titleId, titleName, icon, and userDefinedParam can also be edited during the build process for archived games.)

> No extraction is required at any stage, and the tool is optimized to fully utilize your CPU and memory.

> Based on [MkPFS 0.0.8](https://github.com/PSBrew/MkPFS) by PSBrew.
