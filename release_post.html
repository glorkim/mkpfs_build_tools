MkPFS Build Tool v1.37

Based on MkPFS 0.0.8 by PSBrew  |  제작: Xenogear

MkPFS를 이용하여 PS5 게임 이미지를 자동으로 빌드하는 도구입니다.
폴더 또는 파일(.exfat .ffpkg .rar .zip .7z .zip.001 .7z.001 pfs_image.dat .ffpfsc)을
드래그하면 자동으로 처리됩니다.
압축 후 용량이 약 40~60% 줄어듭니다.
압축 배포된 게임(RAR / ZIP / 7z)은 별도 해제 없이 바로 빌드할 수 있습니다.
(빌드 과정에서 압축 배포된 게임의 타이틀ID, 타이틀명, 아이콘, userDefinedParam도 수정할 수 있습니다.)

※ 모든 과정은 별도 압축해제 없이 진행되며, 본인 CPU와 메모리 모든 자원을 최대한 활용할 수 있게 최적화 되었습니다.

🔄 자동 변환 / 압축 해제

  • 게임 폴더 / RAR·ZIP·7z(분할 포함) / pfs_image.dat / .exfat / .ffpkg → .ffpfsc
  • 압축 배포 게임은 별도 해제 없이 바로 빌드 (스트리밍 처리)
  • .ffpfsc / pfs_image.dat / .exfat → 폴더 추출
  • 압축 후 약 40~60% 용량 절감
  • 출력 파일명 자동 생성: TITLEID-타이틀명 (버전).ffpfsc

🎨 게임 아이콘 교체 v1.37 신규

  • 빌드 시 게임 실행 아이콘 교체 가능
  • 폴더 / RAR·ZIP·7z / pfs_image.dat / .exfat 지원
  • 512×512 고정, 큰 이미지는 비율 유지하며 자동 크기 조정
  • 이미지 드롭 시 미리보기 확인 후 빌드 시 적용
  • param.json 편집 탭에서도 아이콘 변경 가능

✏️ param.json 편집

  • 한국어 환경은 ko-KR 우선 적용
  • 폴더 / 압축 / pfs_image.dat / .exfat 지원
  • 빌드 탭 인라인 편집 + 전용 탭 직접 편집
